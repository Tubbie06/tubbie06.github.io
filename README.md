# thomas-allard.com

Source for Thomas Allard's academic website.

The site is built with Jekyll and contains:

- `_pages/about.md` for the home page
- `_pages/publications.html` and `_publications/` for publications
- `_posts/` for news items
- `files/` for CV and BibTeX files
- `images/` for site assets

Run a local build with:

```bash
bundle exec jekyll build
```
